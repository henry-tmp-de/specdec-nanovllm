# 单次层间 prefill 结果补充

来源为同目录 `summary.json` 与 `evidence/final-01/results/` 的真实记录。Qwen3-4B BF16、单卡、TP1、B4、4K 输入、输出 128、温度 1、显存预算 0.70；每臂各一次显式预热后只计一次，**没有重复区间或置信区间**。四条 code 输入的原 workload Wiki 填充比例为 96.34%–97.29%，不表示自然 4K 任务质量。

三臂各完成 4 个请求、512 个输出 token，合计 12 个请求、1536 个真实输出 token。单次吞吐比为串行/完整 **0.686392×**、流水/完整 **0.673881×**、流水/串行 **0.981774×**。decode 跨度从首个 decode 轮开始到最后一轮结束，包含轮间主机间隔；加载与显式预热不计入主墙钟，但计入 GPU 阶段预算。

混长 B2（257/513）数值 smoke 中，3 对模式合计 102 个 logits 检查和 2592 个逐层 K/V 检查均通过。串行对流水的最大 KL 和最大 KV relative RMS 均为 0；完整对串行及完整对流水的最大 KL 为 0.00047045，最大 KV relative RMS 为 0.04659824，低于预先固定的 0.05，但接近该门槛。最小 top1–top2 margin 为 1.25；这些是有限位置的正确性检查。

三臂各有 127 次普通 decode exact Graph 命中，无 padding 或 fallback；串行与流水各提交并完成 128 个 chunk task，分别使用 1 和 2 个 worker stream。没有采集 NSYS，不能据 stream 提交数声称已测得 GPU kernel 重叠或确定减速原因。`recompile_limit` 警告仅在同进程数值 smoke 日志出现，三条 primary 日志未出现，不能将其当作 primary 减速原因。

本批 4 个守护阶段合计 107.142822 秒，包含加载、编译、热身和清理；旧参数预解析失败未启动 GPU，单独保留。该单点不外推为所有输入、批量或所有流水设计的结果；功能保持默认关闭。
