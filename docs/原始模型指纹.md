```

```

- **不许 `save_pretrained` 回原目录**、不许替换 `model.safetensors`、不许改 `config.json`
- **不许在原目录里放 `quant_config.json`** —— ★ 见下面「为什么这条最要命」
- 不许删原目录里任何文件
- **量化产物一律写到新目录**（既有做法：`Qwen3-4B-int8/`、`Qwen3-0.6B-int8-ffn/`、`Qwen3-0.6B-qffn/`）

## ★ 为什么"别放 quant_config.json"这条最要命

引擎的量化开关是**按目录内容自动判定**的：**目录里存在 `quant_config.json` → 自动开启量化**。
所以一旦这个文件落进原目录：

```
BF16 基线路径 → 指向原目录 → 被【静默量化】 → 我们的基准不再是 BF16
→ 之前所有对照实验失去意义，而且不会报错
```

**这是本项目"静默出错"清单上的第八个潜在坑**，已规避。

for d in Qwen3-4B Qwen3-0.6B; do
  du -sb "$d"
